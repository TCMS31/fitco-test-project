# Fitco users client

React 18 single-page client for the user-management API in [`../api`](../api).

See the [project README](../README.md) for the architecture, the diagrams and
the full quickstart. In short:

```bash
npm install
cp .env.sample .env     # point REACT_APP_API_URL at the API
npm start               # http://localhost:8701
npm test                # Jest + React Testing Library, network fully mocked
npm run lint
```
